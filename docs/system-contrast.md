# System contrast mapping

`SystemContrastManager` is a Foundation integration helper. A consuming WPF application creates it with its application `Resources` after loading its theme and density dictionaries, and disposes it on exit. It observes `SystemParameters.HighContrast` and adds or removes the system-color dictionary last. `SetPreview(null)` follows Windows; `SetPreview(true/false)` is for tests or previews. Theme replacement must preserve the later overlay. Window-local resources can override application resources, so applications must not introduce hardcoded local colors that defeat the mapping.

The overlay maps surface, text, border, selection, selection text, focus, disabled text and status roles to dynamic Windows system colors. Status text remains necessary because system contrast themes need not supply distinct semantic warning or danger colors. Grid selection has separate active and inactive surfaces; the inactive selected row also has an outline, and the focused cell has its own outline. Grid, row and cell focus outlines reserve their border space. `Ops.DataGrid.CellText` and `Ops.DataGrid.NumericCell` explicitly map selected foregrounds; consumers of `DataGridTextColumn` need to set an appropriate `ElementStyle`, including for custom columns. This does not yet cover every WPF control, popup, context menu, dialog or third-party style.

`dotnet run --project Operations.UiCatalog --no-build -- --verify-contrast=artifacts/contrast-check.txt` opened ERP and HMI windows, forced the overlay while the machine was in its current Windows theme, checked system window, selection, selection-text and focus resource values in Dark and Light, verified ERP Standard and HMI Touch sizes, then removed the preview and checked Light was restored. The build and MES regression check also passed. This verifies resource mapping and switching in WPF; it does **not** verify an actual Windows High Contrast theme change, system notifications, screen-reader output, every visual state or contrast of arbitrary third-party controls. Those remain manual verification requirements.
