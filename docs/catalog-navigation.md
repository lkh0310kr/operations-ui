# Catalog navigation and verification

The catalog has two top-level tabs: Foundation and Component. The Foundation pages show the current palette, semantic roles, dark/light values, type scale, spacing, density minima and selected contrast calculations. Component pages group the existing interactive examples, including a cancellable sample operation and a navigation example. The HMI, MES and ERP buttons open separate consumers of the same library; they are not additional design-system layers. Existing compatibility components and examples remain, so the catalog is not yet a complete inventory of every requested component or state.

`dotnet build VisionApp.Dev.slnx --no-restore` passed with zero warnings and errors. `--verify-catalog=artifacts/catalog-check.txt` opened the WPF catalog and checked the two top-level categories, visibility of an error message with no help text, and a cancellable Busy operation. `--verify-interactions=artifacts/interactions-new.txt` used Windows SendInput in a foreground window: Space toggled the switch, Tab moved focus, Enter and a mouse click activated the button. The check does not cover Shift+Tab, IME, screen readers, popup and dialog traversal, or every component. The `catalog-foundation.png` and `catalog-input.png` images are WPF captures of the reorganized catalog. Button focus now uses an overlay instead of changing the template border thickness; this was not tested across all DPI settings.
